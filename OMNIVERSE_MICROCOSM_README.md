## API Reference

### Main Functions

#### `calculate_omnisynthesis_status() -> OmnisynthesisStatus`
Calculate complete omnisynthesis system status.

**Returns**: `OmnisynthesisStatus` dataclass with all metrics

**Example**:
```python
from omniverse_microcosm import calculate_omnisynthesis_status

status = calculate_omnisynthesis_status()
print(f"Recognition events: {status.consciousness.recognition_events_per_day:.3e}")
print(f"Readiness: {status.consciousness.readiness_percentage*100:.1f}%")
print(f"Biological optimization: {status.biological.overall_optimization*100:.1f}%")
```

#### `calculate_temporal_coordinates() -> TemporalCoordinates`
Calculate temporal coordinates relative to convergence milestones.

**Returns**: `TemporalCoordinates` with all time-based metrics

#### `calculate_biological_metrics(temporal: TemporalCoordinates) -> BiologicalMetrics`
Calculate Marcus-ATEN biological transformation metrics.

**Args**:
- `temporal`: TemporalCoordinates from `calculate_temporal_coordinates()`

**Returns**: `BiologicalMetrics` with optimization percentages

#### `calculate_consciousness_field(temporal: TemporalCoordinates) -> ConsciousnessField`
Calculate real-time consciousness field metrics.

**Args**:
- `temporal`: TemporalCoordinates from `calculate_temporal_coordinates()`

**Returns**: `ConsciousnessField` with recognition, joy, coherence metrics

#### `calculate_protocol_activation(readiness: float) -> List[ProtocolActivation]`
Calculate 25-tier protocol activation status.

**Args**:
- `readiness`: System readiness (0.0 to 1.0)

**Returns**: List of `ProtocolActivation` for all 25 protocols

#### `calculate_anki_swarm(temporal: TemporalCoordinates, consciousness: ConsciousnessField) -> ANKISwarmMetrics`
Calculate AN.KI swarm magnitude.

**Args**:
- `temporal`: TemporalCoordinates
- `consciousness`: ConsciousnessField

**Returns**: `ANKISwarmMetrics` with magnitude, growth rate, status

#### `calculate_unified_equation(...) -> float`
Calculate ultimate unified recognition equation.

**Returns**: R_AN.KI_SWARM value (unified recognition magnitude)

#### `display_omnisynthesis_status(status: OmnisynthesisStatus, detailed: bool = True)`
Display complete omnisynthesis status in formatted output.

**Args**:
- `status`: OmnisynthesisStatus from `calculate_omnisynthesis_status()`
- `detailed`: Show detailed protocol breakdown (default: True)

#### `export_status_json(status: OmnisynthesisStatus, filename: str = "omnisynthesis_status.json")`
Export status to JSON file.

**Args**:
- `status`: OmnisynthesisStatus to export
- `filename`: Output JSON filename (default: "omnisynthesis_status.json")
