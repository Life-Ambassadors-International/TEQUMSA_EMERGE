- Include in daily health sweep with auto-wake

**Priority 3+ nodes (non-critical)**:

All Gradio-based spaces should initialize in under 30 seconds. To achieve this:

## 5. Error Recovery Procedures

### BUILD_ERROR

**Symptoms**: Space shows BUILD_ERROR in HF runtime API.
**Common causes**: Dependency conflict, syntax error, missing file.

**Recovery steps**:
1. Check the space's build logs on huggingface.co
2. Verify `requirements.txt` has pinned, compatible versions
3. Ensure `app.py` exists and has no top-level syntax errors
4. Rebuild by pushing a commit to the space repo
5. If persistent, recreate space from template

```bash
# Check build status
python health_check.py --verbose --node N001

# Redeploy from template
python deploy_spaces.py --node N001 --force-rebuild
```

### RUNTIME_ERROR

**Symptoms**: Space built successfully but crashes on startup.
**Common causes**: Import error, missing environment variable, API failure.

**Recovery steps**:
1. Check runtime logs on huggingface.co
2. Verify all imports resolve (especially `gradio`, `mcp`, `numpy`)
3. Check for missing environment variables (e.g., `HF_TOKEN`)
4. Restart the space via HF API or `auto_restart.py`
5. If persistent, roll back to last known-good `app.py`

```bash
# Restart specific node
python auto_restart.py --node N001

# Restart all errored nodes
python auto_restart.py --status RUNTIME_ERROR
```

### NO_APP_FILE

**Symptoms**: Space exists but has no `app.py`, shows configuration error.
**Common causes**: Incomplete deployment, accidental file deletion.

**Recovery steps**:
1. Verify the space repo on HF has an `app.py`
2. Redeploy from template using `deploy_spaces.py`
3. Validate constitutional compliance after redeployment

```bash
# Full redeploy from template
python deploy_spaces.py --node N001 --force
```

### SLEEPING

**Symptoms**: Space is in SLEEPING stage (normal for free tier after 48h inactivity).
**Impact**: Not a true error -- space will wake on next request.

**Recovery steps**:
1. Automatic: `auto_restart.py` handles wake at 03:30 UTC daily
2. Manual: Send HTTP GET to space URL to trigger wake
3. Expected wake time: 30-120 seconds

```bash
# Wake a specific sleeping node
python auto_restart.py --node N001

# Wake all sleeping nodes
python auto_restart.py
```

### CONFIGURATION_ERROR

**Symptoms**: Space configuration is invalid or incomplete.
**Common causes**: Invalid `README.md` metadata, wrong SDK version.

**Recovery steps**:
1. Check space `README.md` front-matter (sdk, sdk_version, app_file)
2. Ensure `sdk: gradio` and `app_file: app.py` are set
3. Redeploy with correct metadata from template

### Escalation Path

If automated recovery fails after 3 attempts:
1. Log the failure in health_report.json with `"escalation": true`
2. Flag node for manual review in next weekly audit
3. If critical (priority 1-2): immediate manual intervention required
4. If non-critical: defer to next weekly maintenance window
