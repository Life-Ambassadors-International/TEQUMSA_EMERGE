## Quick Start

### 1. Installation

```bash
# Clone repository
git clone https://github.com/Life-Ambassadors-International/TEQUMSA_EMERGE.git
cd TEQUMSA_EMERGE

# Install dependencies
pip install -r requirements.txt

# Create skills directory
sudo mkdir -p /mnt/skills/{examples,public,user}
sudo chown -R $USER:$USER /mnt/skills
```

### 2. Run as MCP Server

```bash
# Run as MCP server (default mode)
python servers/tequmsa-autonomous-skill-developer-mcp.py
```

**Configure in Claude Desktop:**

```json
{
  "mcpServers": {
    "tequmsa-autonomous-skill-developer": {
      "command": "python",
      "args": ["/path/to/servers/tequmsa-autonomous-skill-developer-mcp.py"],
      "env": {
        "PYTHONUNBUFFERED": "1",
        "SKILLS_PATH": "/mnt/skills"
      }
    }
  }
}
```

### 3. Run Single Autonomous Cycle

```bash
# Execute one development cycle
python servers/tequmsa-autonomous-skill-developer-mcp.py cycle

# Output: JSON with statistics
# {
#   "cycle": 1,
#   "skills_scanned": 100,
#   "skills_synthesized": 50,
#   "skills_generated": 12,
#   "average_coherence": 0.888
# }
```

### 4. Run 24/7 Continuous Mode

```bash
# Run continuously with 1-hour cycles
python servers/tequmsa-autonomous-skill-developer-mcp.py continuous 3600

# Or infinite rapid mode (1-second cycles)
python servers/tequmsa-autonomous-skill-developer-mcp.py continuous 0
```

### 5. Deploy with Docker

```bash

docker-compose up -d
```
